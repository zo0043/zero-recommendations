# 安装指南

本指南将帮助您完成搜索推荐词采集助手的安装和配置。

## 📋 系统要求

### 浏览器要求
- **Google Chrome** (推荐版本 88+)
- **Microsoft Edge** (基于Chromium的版本)
- **其他基于Chromium的浏览器**

### 操作系统
- **Windows** 10/11
- **macOS** 10.14+
- **Linux** (Ubuntu 18.04+, Debian 10+)

## 🚀 安装方法

### 方法一：开发者模式安装（推荐）

#### 1. 下载扩展文件
```bash
# 克隆项目到本地
git clone <repository-url>
cd zero-recommendations

# 或者直接下载ZIP文件并解压
```

#### 2. 打开Chrome扩展管理页面
- 在Chrome地址栏输入：`chrome://extensions/`
- 或者通过菜单访问：`设置 → 扩展程序 → 管理扩展程序`
- 开启右上角的"开发者模式"开关

#### 3. 加载扩展
- 点击"加载已解压的扩展程序"按钮
- 在文件选择器中选择项目根目录
- 扩展将自动安装并显示在工具栏中

### 方法二：打包安装

#### 1. 打包扩展
- 在扩展管理页面点击"打包扩展程序"
- 选择项目根目录
- 生成`.crx`文件和`.pem`密钥文件

#### 2. 安装包文件
- 拖拽`.crx`文件到Chrome扩展页面
- 确认安装权限
- 扩展将自动安装

## ⚙️ 初始配置

### 1. 权限设置
扩展需要以下权限才能正常工作：
- `storage` - 本地数据存储
- `activeTab` - 当前标签页访问
- `tabs` - 标签页管理
- `scripting` - 脚本注入
- `windows` - 窗口管理

### 2. 平台访问权限
扩展需要在以下平台运行：
- `https://www.xiaohongshu.com/*`
- `https://www.douyin.com/*`
- `https://www.bilibili.com/*`
- `https://www.zhihu.com/*`
- `https://www.baidu.com/*`
- `https://www.google.com/*`
- `https://chat.openai.com/*`

### 3. 基本设置
1. 点击扩展图标打开设置界面
2. 配置默认采集层级（1-3级）
3. 设置导出格式偏好
4. 配置ChatGPT集成参数（如需要）

## 🔧 验证安装

### 1. 检查扩展状态
- 在扩展管理页面确认扩展已启用
- 检查是否有错误信息显示
- 确认权限设置正确

### 2. 测试基本功能
1. 打开支持的平台网站（如百度）
2. 点击扩展图标
3. 输入测试关键词
4. 尝试提取推荐词
5. 验证导出功能

### 3. 常见安装问题

#### 问题：扩展无法加载
**解决方案：**
- 确保开启了开发者模式
- 检查文件路径是否正确
- 查看控制台错误信息

#### 问题：权限被拒绝
**解决方案：**
- 重新检查权限设置
- 确保Chrome版本兼容
- 尝试重新安装扩展

#### 问题：扩展图标不显示
**解决方案：**
- 检查扩展是否被禁用
- 确认Chrome工具栏设置
- 尝试重新启动Chrome

## 🔄 更新扩展

### 手动更新
1. 下载最新版本的代码
2. 在扩展管理页面点击"重新加载"按钮
3. 或者移除后重新安装扩展

### 自动更新（如果通过Chrome商店安装）
- Chrome会自动检查并更新扩展
- 可以在扩展管理页面手动检查更新

## 📚 卸载扩展

1. 打Chrome扩展管理页面
2. 找到搜索推荐词采集助手
3. 点击"移除"按钮
4. 确认卸载操作
